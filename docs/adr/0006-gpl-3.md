# The project is GPL-3.0, not MIT

The template this server started from is MIT. Its plugin engine, Mutagen
([ADR-0003](0003-plugins-through-a-mutagen-helper.md)), is GPL-3.0, as is most of what this ecosystem
builds on — LOOT, Synthesis, Spriggit — and the prior art worth learning from, such as houseCARL and
Phostwood's crash-log rules. Keeping an MIT server at arm's length from a GPL helper over stdio would
rest on a legally grey line, so the whole project is GPL-3.0 instead, which also lets it reuse that
code directly.
